# 🚀 Sahil Jain – Personal Portfolio (React + Vite + TypeScript)

A modern, high-performance developer portfolio rewritten in **React + TypeScript + Vite**, showcasing projects, technical toolkit, certifications, awards, and professional timeline with an award-winning Aurora UI, smooth animations, and responsive interactions.

---

## ✨ Features

- 🎨 **Aurora Mesh & Canvas**: Multi-layered aurora mesh with drifting gradient blobs, live canvas mouse & scroll response, ambient particles, and subtle noise.
- ⚡ **Interactive Hero**: Role typewriter rotating through skills, interactive 3D avatar tilt, and floating specialty badges.
- 📱 **Fully Responsive Glass Navigation**: Floating pill navbar with scrollspy section indicator, "Available for Work" badge, and quick social links.
- 🛠️ **Technical Toolkit**: Categorized skill stacks with interactive badges and tooltips.
- 📂 **Project Showcase**: Rich case study previews with Problem/Solution highlights, tech tags, and code links.
- 📜 **Credentials & Certifications**: Interactive certificate carousel with instant full-screen lightbox preview.
- 📄 **Resume Center**: Direct PDF/image download and modal preview.
- 📬 **Live Contact Flow**: Contact form with validation and instant status feedback.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite
- **Styling**: Aurora Glassmorphism CSS Architecture & Design System
- **Icons**: SVG & Lucide
- **Runtime**: Node.js 22

---

## 🚀 Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
